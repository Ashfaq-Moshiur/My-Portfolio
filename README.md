## ✨ Features

### 🌓 Dual-Mode Theme Engine (Dark & Light)
- **Deep Obsidian Dark Mode (Default)**: Deep obsidian backdrop (`#07090e`), glowing cyan/indigo gradients, subtle mesh lighting blobs, and crisp glassmorphic panels.
- **Clean Modern Light Mode**: High-contrast slate background (`#f8fafc`), elevated white cards, refined border definitions, and tailored particle aesthetics.
- **Persistence & Feedback**: Instant zero-flicker mode switching stored in `localStorage` with non-intrusive notification toasts.

### 🌌 Interactive Ambient Particle Physics Canvas
- Canvas-based particle animation responding to cursor proximity with repulsive force fields.
- Dynamic color adaptation synchronizing with the active Dark/Light theme mode.

### 💻 Interactive Developer CLI Terminal Shell
- Built-in UNIX-inspired terminal interface inside the browser.
- Supports commands: `about`, `education`, `certifications`, `volunteering`, `skills`, `ielts`, `contact`, `clear`, and `help`.
- One-click interactive quick-action pill buttons for seamless mobile and desktop interaction.

### 🎨 Featured Works & Dynamic Portfolio Showcase
- Interactive category filtering: **All Works**, **Graphic Design**, **Ventures & Education**, and **Tech & Innovation**.
- Realistic 3D mouse-tracking card tilt effect with dynamic depth reflection.
- Comprehensive Case Study Modal dialogs presenting project architecture, execution highlights, and typography palettes.

## 🚀 Local Development

To run this portfolio locally on your machine:

### Option 1: Live Server / Python HTTP Server
```bash
# Clone the repository
git clone https://github.com/Ashfaq-Moshiur/My-Portfolio.git

# Navigate into project directory
cd My-Portfolio

# Run with Python
python -m http.server 8080

# Or run with Node.js
npx serve .
```

### Option 2: PowerShell Server
```powershell
powershell -ExecutionPolicy Bypass -File serve.ps1
```

Open `http://localhost:8080` in your browser.
